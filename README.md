# 小松市プレミアム取扱店検索（GitHub Pages 練習版）

## 公開方法
1. GitHubで新しいリポジトリを作成（例: `komatsu-shop-search`）
2. このフォルダ内の `index.html` と `shops.json` をアップロード
3. GitHubリポジトリの `Settings` → `Pages`
4. `Build and deployment` の Source を `Deploy from a branch`
5. Branch を `main`、Folder を `/(root)` にして `Save`
6. 数分待つと公開URLが表示されます

## ファイル
- `index.html` : 検索画面
- `shops.json` : 店舗データ

## 注意
これはGitHub Pages公開を体験するための試作版です。
店舗情報は小松市公開PDF（令和8年5月18日時点）から一部を抽出しています。
全店舗版へは `shops.json` を差し替えるだけで拡張できます。
